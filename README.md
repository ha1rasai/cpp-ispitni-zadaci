# Ispitni zadaci iz C++ (Programiranje 2)

Rješenja ispitnih zadataka iz predmeta Programiranje 2, svako u jednom fajlu.

| Fajl | Sadržaj |
|---|---|
| `ispitni-juli-g1.cpp` | ispitni rok juli, grupa 1 |
| `ispitni-juli-g2.cpp` | ispitni rok juli, grupa 2 |
| `zadatak-kategorija.cpp` | zadatak "Kategorija" |

Korišteno: klase i nasljeđivanje, šabloni (templates), dinamička alokacija memorije, operatori,
izuzeci, `std::vector`, regularni izrazi (`<regex>`), niti (`<thread>`, `<mutex>`).

## Pokretanje

```
g++ -std=c++17 -pthread ispitni-juli-g1.cpp -o g1
./g1
```

ili otvoriti fajl u Visual Studiju kao novi C++ projekat (Console App).
